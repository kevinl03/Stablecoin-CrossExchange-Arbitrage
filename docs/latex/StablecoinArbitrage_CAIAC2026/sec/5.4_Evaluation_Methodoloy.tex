\subsection{Evaluation Methodology}
\label{sec:evaluation}

We evaluate along five dimensions: cached-graph heuristic comparison, graph scaling, temporal robustness (8-hour overnight campaign), quote staleness under execution delay, and hyperparameter sensitivity. \emph{Cached} experiments freeze the graph from a single snapshot, isolating algorithmic differences; \emph{live} experiments include API I/O overhead. We report success rate, conditional average profit, node expansions, wall-clock time, path length, and path type (intra- vs.\ cross-exchange).
