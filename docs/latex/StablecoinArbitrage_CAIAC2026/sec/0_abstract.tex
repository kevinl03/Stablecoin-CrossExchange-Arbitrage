\begin{abstract}
Cross-exchange cryptocurrency arbitrage enables low-risk profit from price discrepancies across exchanges, yet existing approaches predominantly employ negative cycle detection algorithms (e.g., Bellman--Ford) that target opportunity identification rather than execution feasibility. We introduce an execution-aware pathfinding framework for stablecoin cross-exchange arbitrage using A* search with domain-specific guidance heuristics. The problem is modelled as a weighted directed graph where nodes represent (exchange, stablecoin) pairs across 12 major centralized exchanges (41~nodes, 864~edges) and edges encode trades and transfers with real-world execution costs including trading fees, order-book slippage, withdrawal fees, gas costs, transfer delays, and exchange reliability risks. We propose three guidance heuristics, $h_1$ (liquidity), $h_2$ (slippage), $h_4$ (chain congestion and exchange risk via Weighted~A*), and a multi-start search-control strategy. Evaluation over 7{,}200 search instances in an 8-hour overnight campaign, graph scaling from 4 to 12 exchanges, sensitivity sweeps, and cached-graph benchmarks reveals differentiated heuristic roles: $h_2$ reduces node expansions by 29\% relative to Dijkstra while matching profit, and $h_4$ provides risk-aware guidance at Dijkstra-class latency (P99 = 33\,ms) with zero API overhead. The execution-aware graph formulation itself is the primary contribution: Dijkstra alone achieves 100\% success across overnight runs, demonstrating that embedding real-world frictions into edge weights makes any shortest-path algorithm a viable arbitrage planner. Code and data are available at \url{https://anonymous.4open.science/r/Stablecoin-CrossExchange-Arbitrage} (anonymized for review).
\end{abstract}
