\subsection{Evaluation Methodology}
\label{sec:evaluation}

We evaluate our algorithms along four dimensions: correctness validation,
deterministic heuristic comparison, stochastic robustness analysis, and
standardized performance metrics. This multi-layered methodology ensures that
reported improvements reflect both theoretical soundness and practical
execution behavior under realistic market variability.

% ---------------- 5.4.1 ----------------
\subsubsection{Live Market Data Heuristic Comparison}

In deterministic experiments, we fix:
\begin{itemize}
    \item Graph snapshot (single market capture)
    \item Starting nodes (Binance:USDT, Kraken:USDT, Binance:BUSD)
    \item Order sizes (\$100, \$1{,}000, \$10{,}000)
\end{itemize}

This controlled setup isolates the effect of heuristic guidance on:
\begin{enumerate}
    \item Path discovery success
    \item Net profitability
    \item Search runtime
    \item Path length
\end{enumerate}

Across deterministic runs, all successful algorithms converged to a
transfer–trade pattern (path length 3). Profit scaled linearly with order size,
confirming multiplicative cost modeling correctness. However, runtime and
failure behavior varied significantly across heuristics, revealing meaningful
differences in pruning aggressiveness and exploration breadth.

% ---------------- 5.4.3 ---------------
\subsubsection{Performance Metrics}

We report four standardized evaluation metrics; success rate, conditional average profit, runtime, and path length. 

$
\text{Success Rate} =
\frac{\text{\# profitable runs}}{\text{\# total runs}} 
$


$\text{Conditional Average Profit} = \mathbb{E}[\text{Profit} \mid \text{Success}]
$

Profit is measured net of trading, withdrawal, and gas fees, which are fees associated with transferring on the blockchain.

Importantly, profit statistics are conditioned on successful runs.
Failed runs (no profitable path found) are excluded from average
profit computation but reflected in the success rate metric.

These metrics jointly evaluate economic quality, computational efficiency,
and algorithmic robustness, providing a comprehensive assessment of
heuristic effectiveness.
